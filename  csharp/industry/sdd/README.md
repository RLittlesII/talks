## Abstract

Old and busted: the 1998 requirements spec. New hotness: vibe coding. Newer hotness: the 1998 requirements spec. The agent writing your code builds exactly what you wrote and never asks what you meant, so the document we buried twenty years ago is suddenly the best prompt you have. This talk covers what goes in a spec an agent can build from, and the loop of tests, lessons, and skills that keeps it honest.
