# Abstractions and Composition

This directory contains the [Slidev](https://sli.dev/) presentation for the talk on C# Abstractions and Composition.

## Getting Started

To run the presentation locally:

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Start the development server**:
    ```bash
    npm run dev
    ```

3.  **View the slides**:
    The slides will automatically open in your browser, or you can visit [http://localhost:3030](http://localhost:3030).

## Other Commands

-   **Build for production**:
    ```bash
    npm run build
    ```
    The output will be in the `dist` directory.

-   **Export to PDF**:
    ```bash
    npm run export
    ```
