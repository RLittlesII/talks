## Abstract

Old and busted: the 1998 requirements spec. New hotness: vibe coding. Newer hotness: the 1998 requirements spec. The agent writing your code can confidently follow the wrong requirement, so the document we buried twenty years ago is suddenly one of your most important inputs—and its changes need checking too. This talk follows how agents use a spec, and the loop of tests, lessons, and skills that keeps the workflow honest. Along the way, a horror story about my precious tokens leads to SDD Inception: using SDD to build Specht, a tool for SDD. Learn why deterministic checks belong in the process, whichever tool you choose.
