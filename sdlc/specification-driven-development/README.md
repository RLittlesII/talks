## Abstract

Old and busted: the 1998 requirements spec. New hotness: vibe coding. Newer hotness: the 1998 requirements spec. The agent writing your code can confidently follow the wrong requirement, so the document we buried twenty years ago is suddenly one of your most important inputs—and its changes need checking too. This talk follows how agents use a spec, and the loop of tests, lessons, and skills that keeps the workflow honest. Along the way, a horror story about my precious tokens leads to SDD Inception: using SDD to build Specht, a tool for SDD. Learn how to monitor the process, keep humans responsible for intent and acceptance, and build deterministic tools for recurring drift. BDD and TDD remain essential: agreed examples and executable tests connect the claims to evidence. AI helps maintain those connections; verification needs more than another model review.
